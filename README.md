ProbeTect
A web-based platform designed to automate quiz generation from uploaded lesson files and streamline lesson planning for educators. ProbeTect helps teachers save time by automatically generating multiple-choice, true/false, and fill-in-the-blank questions from PDFs, DOCX, and TXT files.

🧩 Tech Stack Used
Backend: Python, Django Framework
Frontend: HTML, CSS, JavaScript
Database: SQLite (development)
APIs & AI Tools: Deepseek, ChatGPT, Gemini
Version Control: Git & GitHub
Design Tools: Figma

⚙️ Setup & Run Instructions
1. Clone the Repository
git clone https://github.com/<your-org-or-username>/ProbeTect.git
cd ProbeTect

2. Create and Activate a Virtual Environment
python -m venv venv
venv\Scripts\activate      # For Windows
source venv/bin/activate   # For macOS/Linux

3. Install Dependencies
pip install -r requirements.txt

4. Run Database Migrations
python manage.py makemigrations
python manage.py migrate

5. Start the Development Server
python manage.py runserver

6. Access the Application

Open your browser and go to:
👉 http://127.0.0.1:8000/
